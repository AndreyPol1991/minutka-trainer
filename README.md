# Неделя в «Минутке» — практикум по брокерам сообщений

Практический тренажёр для системных аналитиков. Сквозной кейс — сервис доставки продуктов «Минутка»: в пятницу на акции синхронные вызовы уронили оформление заказов, и команда переводит интеграции на брокер сообщений. Вы — системный аналитик команды заказов.

**Открыть:** https://andreypol1991.github.io/minutka-trainer/

Семь дней — семь тренировок:

- **Понедельник.** Созвон с заказчиком: вопросы, без которых брокер не спроектировать; пиковая нагрузка в сообщениях в секунду.
- **Вторник.** Карта интеграций: где синхронный запрос, где топик, где очередь, где выгрузка.
- **Среда.** Доска событий: факты вместо команд, имена событий, конверт события.
- **Четверг.** Kafka или RabbitMQ, ключ сообщения, число партиций, группа консюмеров.
- **Пятница.** Ни потерять, ни задвоить: acks, реплики, коммит офсета, идемпотентность получателя.
- **Суббота, 03:12.** Ночной инцидент: ядовитое сообщение и DLQ, совместимость схем, outbox.
- **Воскресенье.** Нагрузочный тест с тройным пиком и постановка задачи на разработку.

Каждая тренировка: «1. Теория» — лаборатории, где всё можно потрогать руками; «2. Практика» — задания с проверкой и разбором. Решения переносятся из дня в день.

Прогресс хранится в браузере. Отчёт для преподавателя — кнопка «Отчёт» вверху страницы: в конце отчёта код работы, по которому преподаватель заново проверяет все ответы.
